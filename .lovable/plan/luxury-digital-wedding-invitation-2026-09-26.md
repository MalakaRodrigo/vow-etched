# Luxury Digital Wedding Invitation

## Build
- Replace the blank page with a mobile-first, single-page invitation that opens like a printed wedding card.
- Use a warm ivory, champagne, charcoal, and muted botanical palette with editorial serif typography.
- Keep all placeholder names, dates, venues, story text, schedule, links, and image references in one editable configuration.

## Experience
- Add the opening cover, photographic invitation, live countdown, story, ceremony and reception details, schedule, asymmetric gallery, venue, RSVP form, and closing message.
- Add a discreet floating section menu, smooth scrolling, restrained reveals, and reduced-motion support.
- Build a full-screen gallery viewer with previous/next controls and keyboard support.
- Validate RSVP entries in the browser and show a clear success state, without storing or sending responses yet.

## Photography
- Generate a cohesive set of refined placeholder wedding photographs, optimized and lazy-loaded where appropriate.
- Use intentional mobile and desktop crops so the invitation remains polished from 360px through desktop.

## Verification
